# Roadmap

Порядок фич. Каждая — спека в `docs/specs/NNNN-name/` (`/new-spec`), ветка `feat/NNNN-...`, PR.
Когда спека реализована — отметить здесь и взять следующую.

| #    | Спека                                                                                  | Статус                           | Зачем именно сейчас                                                    |
| ---- | -------------------------------------------------------------------------------------- | -------------------------------- | ---------------------------------------------------------------------- |
| —    | Каркас репозитория, CI                                                                 | готов                            | Без него нечего проверять и собирать                                   |
| 0001 | Оболочка: роутер, UI-кит, обработка ошибок API                                         | готов                            | Основа всех экранов; работает с PAT через dev-прокси                   |
| 0002 | Деплой: образ со статикой, compose за Traefik, релиз и выкатка, заголовки безопасности | реализована, ждёт первой выкатки | Живой сайт на `WEB_HOST`; `/api` на этом хосте даёт спека 0008 бэкенда |
| 0003 | Вход через бэкенд, сессия в cookie                                                     |                                  | Ждёт спеку 0008 бэкенда (ADR 0013 там, ADR 0003 здесь)                 |
| 0004 | Дерево папок и задач: просмотр и смена статуса                                         |                                  | Главная ценность сайта                                                 |

Дальше: «что делать дальше» по приоритету, разбор «Входящих», сравнение с Flutter-сайтом и выбор основного.

## Связь с бэкендом

- Спека 0008 бэкенда (`../backend/docs/specs/0008-browser-sessions/`) делает вход через cookie и маршрут
  `/api` на хосте веба. Её первый шаг — маршрут — можно выпустить отдельно, раньше входа: тогда
  задеплоенный сайт (0002) сразу видит бэкенд.
- Деплой веба повторяет подход бэкенда (`../backend/docs/adr/0011-deploy-behind-traefik.md`): образ в ghcr
  по тегу, compose на сервере, выкатка из GitHub Actions с подтверждением.
