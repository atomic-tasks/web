# 0005. Статика в образе nginx, заголовки безопасности в конфиге nginx

Статус: принят (спека 0002)

## Контекст

Сайт после `pnpm build` — папка файлов `dist/` (ADR 0001). На сервере уже работает Traefik: он принимает
HTTPS, выпускает сертификаты и маршрутизирует запросы по хосту и пути, но файлы с диска не отдаёт
(в Traefik v3 нет файлового сервера, только сторонние плагины). Значит, нужен контейнер, который отдаёт
`dist/` и делает то, чего Traefik не умеет:

- **SPA-fallback.** Адреса разбирает роутер в браузере (ADR 0004): на любой путь, которого нет на диске,
  нужен `index.html`.
- **Кэш по типу файла.** `assets/*` с хэшем в имени — надолго, `index.html` — без кэша, иначе после релиза
  остаётся старый бандл.
- **Заголовки безопасности.** CSP обязательна (ADR 0003): httpOnly-cookie защищает токен, но не действия
  от имени пользователя, если на страницу попал чужой скрипт.

Ещё одно ограничение пришло от бэкенда: спека 0008 бэкенда отдаёт на хосте сайта (`WEB_HOST`) только `/api/`.
`/health`, `/docs`, `/mcp` — только на `API_HOST`. ADR 0003 и `architecture.md` рассчитывали на `/health`
на хосте сайта.

## Рассмотренные варианты

### Сервер статики

|               | nginx (`nginx-unprivileged`, alpine) | Caddy                               | static-web-server             |
| ------------- | ------------------------------------ | ----------------------------------- | ----------------------------- |
| Память        | ~5–10 МБ                             | ~20–40 МБ                           | ~5 МБ                         |
| Без root      | Да, готовый образ, порт 8080         | Нужна настройка                     | Да                            |
| Конфиг        | Свой язык, известны подводные камни  | Caddyfile, короче                   | Флаги и TOML, меньше гибкость |
| Распространён | Самый, агенты пишут его уверенно     | Широко                              | Узко                          |
| Лишнее        | Нет                                  | Свой TLS и ACME — дублирует Traefik | Нет                           |

### Где ставить заголовки

- **В nginx.** Fallback, кэш и заголовки — в одном конфиге внутри образа. Версионируются с релизом,
  проверяются в CI на собранном образе, локально — то же, что в проде.
- **В middleware Traefik (labels в compose).** Заголовки отдельно от образа, правила ответа в двух местах,
  проверить можно только на сервере.

## Решение

- **Образ `ghcr.io/atomic-tasks/web`:** сборка в multi-stage Dockerfile, рантайм —
  `nginxinc/nginx-unprivileged` (alpine, тег закреплён), порт `8080`. Конфиг — `deploy/nginx/`.
- **Заголовки безопасности, кэш и fallback — в конфиге nginx.** Заголовки — в отдельном файле, который
  подключается в каждый `location`: у nginx `add_header` внутри `location` отменяет заголовки уровня `server`.
- **CSP строгая:** `default-src 'none'`, всё остальное — `'self'`, `frame-ancestors 'none'`. Ослабление
  (`'unsafe-inline'`, `data:` для шрифтов и т. п.) — только новым ADR с причиной.
- **Два inline-стиля React Aria — по хэшу.** `usePress` вставляет `<style>` с `touch-action` для нажимаемых
  элементов (без него двойной тап по кнопке на телефоне масштабирует страницу), `usePreventScroll` — с
  `overscroll-behavior` на время модалки (без него на iOS прокручивается страница под модалкой). Nonce на
  статике невозможен (он свой у каждого ответа), `'unsafe-inline'` разрешил бы любой стиль. В `style-src` —
  два `'sha256-…'`; тест `deploy/csp.test.ts` вычисляет их из установленного React Aria и падает, если текст
  стилей изменился (PR обновления React Aria).
- **`/api/` на сервере статики — `503`.** Запрос туда попадает, только если в Traefik нет роутера бэкенда
  (бэкенд остановлен или не выкачен): клиент покажет «Нет связи с сервером», а не ошибку разбора HTML.
- **Индикатор бэкенда переходит на `GET /api/v1/health`** — когда путь появится в контракте бэкенда. Это
  уточняет ADR 0003: на хосте сайта у бэкенда только `/api/`.

## Последствия

- Проверка ответов сервера (`deploy/smoke.sh`) одна для CI и выкатки: сломанный конфиг ловится до релиза.
- CSP запрещает inline-скрипты и стили в HTML. Vite их не генерирует; React и React Aria ставят стили
  через CSSOM, CSP это не ограничивает. Новая библиотека, которая вставляет `<style>`, сломается заметно
  (ошибка в консоли), а не тихо.
- HSTS ставит nginx; если Traefik тоже ставит его всем хостам, заголовок дублируется — безвредно.
- Конфиг nginx — ещё один язык в репозитории. Его поведение закреплено проверками `smoke.sh`, а не только
  ревью.
