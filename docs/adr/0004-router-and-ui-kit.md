# 0004. Роутер TanStack Router и UI-кит React Aria Components

Статус: принят (спека 0001)

## Контекст

ADR 0001 оставил выбор роутера и UI-кита спеке оболочки. Требования: SPA за логином, лёгкая статика,
код в основном пишут агенты; впереди дерево папок, списки, drag-and-drop, модальные окна (спека 0004
roadmap). Из `AGENTS.md`: сначала возможности платформы, потом библиотеки; данные — только через хуки
Orval/TanStack Query.

Роутер отвечает за соответствие адреса экрану, переходы без перезагрузки, общую разметку экранов,
состояние в адресе (search-параметры) и ошибки на уровне маршрута. UI-кит — за поведение и доступность
интерактивных элементов (клавиатура, фокус, скринридер), иногда ещё за внешний вид и готовые сборки.

## Решение

- **TanStack Router, маршруты в коде** (`src/app/router.tsx`), без Vite-плагина и сгенерированного дерева
  маршрутов: маршрутов немного, а лишняя генерация — ещё одна вещь, которую CI должен сверять. Главный
  довод — типизированные параметры и search-параметры для экранов 0004 и общий с Query подход к загрузке.
- **React Aria Components + свой CSS** на токенах в CSS-переменных (`src/shared/ui/theme.css`). Дерево
  с клавиатурой и drag-and-drop — самое сложное, что ждёт сайт, и оно есть готовым и доступным. Стили
  наши: без Tailwind и PostCSS, простые вещи берём у платформы.
- Связка: `shared/ui/Link` = `createLink` TanStack Router над `Link` React Aria (адрес проверяет `tsc`),
  `RouterProvider` React Aria внутри корневого маршрута — ссылки и меню React Aria переходят через роутер.
- CSS — обычные файлы рядом с компонентом, классы с префиксом по имени компонента (`.Button`,
  `.Layout-header`). CSS-модули не подошли: при `noUncheckedIndexedAccess` класс модуля имеет тип
  `string | undefined`, а React Aria (`exactOptionalPropertyTypes`) его не принимает.

## Последствия

- Бандл: 78.9 → 118.7 kB gzip на оболочке (спека 0001); дерево и DnD в 0004 добавят ещё часть React Aria.
- Ссылка на несуществующий маршрут не компилируется; маршруты и их типы регистрируются в одном месте.
- Внешний вид — наша работа: каждый новый компонент React Aria получает стили на токенах `theme.css`.
- Глобальные CSS-классы: конфликт имён предотвращает только соглашение о префиксе.
