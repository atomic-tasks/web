# 0002. Раскладка `src/` и README-контракты модулей по EGM

Статус: принят (эксперимент только в этом репозитории)

## Контекст

Код в основном пишут агенты. Каждый новый сеанс агента начинается без памяти: чтобы безопасно поменять
модуль, ему нужно понять, что модуль отдаёт наружу и какие правила нельзя нарушать, не читая все файлы.
`AGENTS.md` описывает правила репозитория целиком, но не конкретные модули.

Elephant & Goldfish Model (EGM, плагин `egm`) предлагает README-контракт в каждом модуле: Interface,
Invariants, Side Effects. Ревьюер без контекста («goldfish») должен понять модуль по одному README.
Инструменты EGM умеют генерировать такие контракты по коду (`egm-bootstrap`) и искать расхождения
с кодом (`egm-drift-report`).

## Решение

**Раскладка `src/`:**

```
src/
├── main.tsx       # точка входа
├── app/           # оболочка: App, роутер, провайдеры
├── api/           # клиент к бэкенду; generated/ — типы из openapi.json
├── auth/          # сессия и текущий пользователь
├── features/      # по папке на область: folders/, tasks/, …
└── shared/
    ├── ui/        # общие компоненты без знания о предметной области
    └── lib/       # утилиты
```

Импорты направлены вниз: `app → features → shared, api, auth`. Фичи друг друга не импортируют — общее
переезжает в `shared/`. Папка создаётся, когда в ней появляется код.

**Контракты:**

- `README.md` по шаблону `docs/module-readme-template.md` в каждом модуле. Папки только с подпапками
  (`src/`, `features/`, `shared/`) получают индекс со ссылками на дочерние контракты.
- Контракт на границе модуля, а не на папку каждого компонента: у компонента редко есть свои инварианты,
  а сотня пустых README только тратит контекст агента.
- Заголовки разделов по-английски (по ним работают инструменты EGM), текст по-русски.
- Только факты из кода. Планы — в roadmap и спеках.
- `src/api/generated/` исключён (`.egmignore`).

**Процесс:** из EGM берём Goldfish-ревью спеки перед реализацией (`egm-review` / `egm-lite`)
и drift-report перед релизом. Формат спек остаётся нашим (`docs/specs/NNNN/`). Каталог `docs/designs/`
из EGM не заводим: он дублировал бы спеки и ADR. Артефакты EGM — в `scratch/egm/`.

## Последствия

- Агент читает пару коротких README вместо всех файлов модуля, инварианты записаны явно.
- Контракты нужно поддерживать: правило «изменил интерфейс — обнови README в том же коммите» в `AGENTS.md`,
  пункт в шаблоне PR, drift-report перед релизом.
- Для контрибьюторов без плагина `egm` контракты — обычный markdown.

**Оценка эксперимента** — после спек оболочки и дерева задач (roadmap 0001, 0003):
сколько расхождений находит drift-report, пользуются ли агенты контрактами (ссылаются ли на инварианты),
сколько времени уходит на поддержку. По итогам — ADR: перенести практику в общие гайды и прогнать
`egm-bootstrap` по бэкенду, или отказаться.
