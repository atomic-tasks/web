# features/explorer

## Overview

Экраны «Текущие» и «Проводник» (спека 0005): просмотр дерева папок и задач и смена статуса. Все данные —
от бэкенда через хуки Orval; приоритет, `active_branch` и состав списков клиент не пересчитывает.

## Interface

- `CurrentPage` — «Текущие»: `filter` (`in_progress` | `todo` | не задан — открытые по умолчанию бэкенда), `actions` (слот
  верхней панели). Список `list_nested_tasks` корня, `limit` 50.
- `ExplorerPage` — «Проводник»: `folderId`, `showClosed` (`include_closed`), `actions`. Подпапки и задачи одной папки,
  «назад» — ссылка на предка из `path`, переключатель «Показать завершённые», подпись неактивной ветки.
- `ExplorerRoot` — то же для корня: ждёт `get_root_folder`, затем показывает `ExplorerPage`.
- `ItemDialog` (`DialogItem`) — окно правки: название, описание, вес, статус; приоритет только показывается. Открывается
  нажатием на строку задачи или значком карандаша у папки (нажатие на папку открывает её; статус папки меняется только в этом окне).
- Внутри: `useSaveItem` (`PATCH` полей + отдельный `POST` статуса), `TaskRow`, `FolderRow` (строки `ListGroup`), `useChangeTaskStatus` (оптимистично, с откатом),
  `taskCache` (правка и откат кэша),
  `statusLabels` (подписи статусов), `pathLabel` (`formatPath`, `formatPriority`).

## Invariants

- Запросы — только сгенерированные хуки из `api/generated/`; своих ключей Query нет.
- Клиент ничего не фильтрует и не считает: неактивные ветки и порядок задач приходят от бэкенда.
- Слова для значений статусов API — только в `statusLabels.ts`.
- Состояние (папка, фильтр, «завершённые») — в адресе; в браузерных хранилищах ничего.
- Не импортирует другие фичи и `app/`; профиль и прочее приходит слотом `actions`.
- Тексты задач и папок выводятся только как текст.

## Side Effects

- Запросы `GET` папок и задач; `POST` смены статуса задачи/папки; `PATCH` названия, описания и веса из `ItemDialog`.
- После любой смены статуса инвалидируются все списки дерева (`…/children`, `…/nested-tasks`).
- Навигация внутрь папки — через роутер, с `viewTransition`.
