# app

## Overview

Оболочка приложения: корневой компонент, провайдеры и то, что видно на всех экранах. Сейчас это каркас —
заголовок и индикатор связи с бэкендом. Роутер и разметка экранов появятся здесь со спекой оболочки
(`docs/roadmap.md`).

## Interface

- `App` (`App.tsx`) — корневой компонент, монтируется из `src/main.tsx`. Оборачивает приложение
  в `QueryClientProvider` с единственным `QueryClient`.
- `HealthStatus` (`HealthStatus.tsx`) — временный индикатор: `useHealth()` → «доступен» / «недоступен».
  Используется только в `App`.

## Invariants

- `app/` импортирует фичи и общие модули, но его не импортирует никто, кроме `src/main.tsx`.
- `QueryClient` один на приложение и создаётся только здесь.
- В бэкенд ходит только через хуки из `../api/generated/`.

## Side Effects

- `HealthStatus` при монтировании делает один запрос `GET /health` без повторов (`retry: false`).

## Verification
